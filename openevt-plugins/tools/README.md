## Lightning parameter tuning

The optimizer uses the actual Rust timestepper through the optional PyO3
extension. Build the extension from this crate, then run the tuner:

```sh
cd /path/to/openevt-plugins/tools
maturin develop --manifest-path ../Cargo.toml --features python
uv run tune_lightning.py ../test.mp4 --trials 200 --output lightning-best.toml
```

Each Optuna trial creates `openevt_plugins.Simulator` with that trial's TOML
parameters and consumes every event batch generated by Rust. The Python code
only scores the resulting events against the video contrast; it no longer
reimplements the timestepper or noise model.
